# LJT-Homepage

Personal academic homepage for Junteng Liu, built using the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template.

This repository was forked from [academicpages/academicpages.github.io](https://github.com/academicpages/academicpages.github.io) and customized with personal information.

## Local Development

1. Clone the repository.
2. Install dependencies: `bundle install`
3. Run the local server: `jekyll serve -l -H localhost`
4. Access the site at `localhost:4000/LJT-Homepage/`
